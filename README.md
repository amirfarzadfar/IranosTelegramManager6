# Iranos Telegram Manager — نسخه اولیه

اپلیکیشن اندرویدی فارسی برای مدیریت مخاطبان رضایت‌داده و آماده‌سازی پیام‌های تبلیغاتی ایرانوس.

## قابلیت‌های نسخه اولیه
- داشبورد فارسی با برند ایرانوس
- ثبت دستی مشتریانی که رضایت دریافت پیام را داده‌اند
- ساخت و پیش‌نمایش متن تبلیغ
- اشتراک‌گذاری متن از طریق منوی اندروید (از جمله تلگرام)
- صفحه برنامه‌ریزی اولیه

## محدودیت‌های عمدی
این نسخه به اکانت شخصی تلگرام وارد نمی‌شود، دفترچه تلفن را استخراج نمی‌کند و پیام خصوصی انبوه یا خودکار ارسال نمی‌کند. ارسال به مخاطبان باید با انتخاب و اقدام دستی کاربر و فقط برای کسانی انجام شود که دریافت پیام را پذیرفته‌اند.

## ساخت در Android Studio
1. Android Studio را نصب کن.
2. پوشه پروژه را باز کن.
3. اجازه بده Gradle Sync کامل شود.
4. گوشی را با USB debugging وصل کن یا شبیه‌ساز بساز.
5. از منوی Build گزینه Build APK(s) را بزن.

حداقل Android: 8.0 (API 26)
شناسه برنامه: `ir.iranos.manager`
نسخه: `0.1.0`
